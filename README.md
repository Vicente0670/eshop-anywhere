# eShop Anywhere

Listen to music from the 3DS/Wii U eShops while you shop

As of **version 1.0.0**, this extension is only supported on **Chromium-based** browsers **v109+**.
Will port to Firefox and lower versions of Chromium soon.

## How to Install

### Step 1
Download the CRX file from [the latest release](https://github.com/OWNER/REPOSITORY/releases/latest).

### Step 2
Go to `chrome://extensions`, and toggle **Developer Mode ON** in the top-right corner.

To confirm this works, open up [Amazon](https://amazon.com/) or [Steam](https://store.steampowered.com/). These are the only websites that work, and I plan to add more sites soon.
If you want a site to be added, create an issue on this repo.

## Features
* Features all eShop tracks from the 3DS and Wii U eShops
* Constant music playback across sites
* Dynamic music based on if you're shopping, in your wishlists, in your settings, etc.
* Media settings to play/pause, switch tracks, and seek a track's timeline. Basically everything you need in a music player.
* Vibe to one song if you'd like, or loop through all of them for some nostalgia. Yes, I made this extension purely for nostalgia purposes.

## FAQ
In reality, as of writing this, nobody asked these questions.

### Why doesn't the extension work?
The extension only works on Chromium browsers v109+ that support Manifest V3 extensions.
The browser should also support the Offscreen API. The extension will not depend on this API in further updates.

### When will you not depend on the Offscreen API?
In a future update that will also port the extension to Firefox.
